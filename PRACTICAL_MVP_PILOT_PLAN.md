# Practical MVP Pilot Plan — 7-Day Sourcing Operations

**Objective**: Use **The Sourcing Manager OS** for 7 consecutive days to manage real-world broker activation and lead intake for **The Wadhwa Wise City, Panvel**, starting with **Jitu Gupta (JSN Enterprise)** from Mira Road.

---

## 1. Pilot Schedule

| Day | Focus | Primary Activity |
| :--- | :--- | :--- |
| **Day 1** | **Data Seeding** | Add 25–50 top brokers from your network into the CRM. |
| **Day 2-3** | **Calling Sprint** | Use only the app for broker calls and follow-up updates. |
| **Day 4-5** | **Lead Intake** | Log every lead received via brokers directly into the system. |
| **Day 6** | **Visit Linkage** | Connect leads to site visits and verify via GPS/Photo. |
| **Day 7** | **Performance Review** | Use the Dashboard to identify your Top 5 brokers and pipeline health. |

---

## 2. Success Criteria

The pilot is successful if Vinod can answer these questions on Day 7 without checking WhatsApp or spreadsheets:

1. **Who are my Top 5 brokers** by lead conversion this week?
2. **How many brokers** are stuck in the `Project Explained` stage?
3. **How many follow-ups** did I miss or complete today?
4. **Are my site visits** correctly attributed to the source broker?

---

## 3. Operational Rules (The Pilot Constitution)

- **Zero-PII Export**: No contact details should be exported or screenshotted.
- **Secure Calls Only**: Use the in-app "Secure Call" button to preserve the audit trail.
- **Immediate Intake**: Log leads as soon as they are received to ensure "Broker Lock" integrity.

---

## 4. Support & Incident Plan

- **Technical Friction**: Log any UI slowness or button errors in the `PILOT_FEEDBACK_LOG.md`.
- **Security Check**: Run `python scripts/security-check.py` every morning to ensure configuration remains hardened.
